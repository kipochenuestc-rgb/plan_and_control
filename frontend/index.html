后轴中心的阿克曼运动学模型

以白点标记的后轴中心为车辆位置参考点。地图坐标系固定，X 轴向右、Y 轴向上。

变量、单位与方向约定
变量含义单位 / 约定
x、y后轴中心在地图坐标系中的位置m（米）
t仿真时间s（秒）
ψ车身航向角：车头方向相对地图 X 轴的夹角逆时针为正；0 表示车头朝右
v后轴中心沿车身纵向的有符号速度m/s；前进为正，倒车为负
δ自行车模型的等效前轮转角，相对车身纵向；不是方向盘转角左转为正，右转为负
L轴距：前轴中心到后轴中心的距离m；对应右侧“轴距 L”参数
T轮距：同一轴左右轮中心之间的距离；此模型前后轮距相同m；对应右侧“轮距 T”参数
R后轴中心到瞬时转动中心的有符号半径m；左转为正，右转为负；几何半径为 |R|，直行时趋于无穷大
δin靠近瞬时转动中心的内侧前轮转角，相对车身纵向左转时是左前轮，右转时是右前轮；符号与 δ 相同
δout远离瞬时转动中心的外侧前轮转角，相对车身纵向左转时是右前轮，右转时是左前轮；符号与 δ 相同
sign(δ)取转角的正负符号左转为 +1，右转为 −1；以下半径公式仅用于 δ ≠ 0
ẋ、ẏ、ψ̇变量上方的点表示对时间求导，分别是 X/Y 方向速度、航向角速度ẋ、ẏ 为 m/s；ψ̇ 为 rad/s

公式计算中的角度使用弧度（rad）；右侧仪表将角度转换为度（°）显示。sin、cos、tan 分别表示正弦、余弦、正切。

车辆位姿随时间变化：

ẋ = v cos ψẏ = v sin ψψ̇ = v tan δ / L

当 δ ≠ 0 时，后轴转弯半径为：

R = L / tan δ

前轮的内、外轮转角分别满足：

tan δin = L / (R − sign(δ)T/2)tan δout = L / (R + sign(δ)T/2)

内侧前轮的转角绝对值更大，因此内外前轮不会平行。

这是无侧滑、低速条件下的纯运动学模型。W/S/A/D 为连续按键控制；松开按键后，速度和转向会自然回正、衰减。
